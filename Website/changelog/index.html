Version History & Changelog

All notable changes to Flowback follow Semantic Versioning and the Keep a Changelog standard.

Version 1.0.0

Initial Production Release • 2026-10-16
Download v1.0.0

Added

  • Official Agent Providers: First-class support for Google Antigravity (hook lifecycle + transcript discovery), Claude Code, OpenAI Codex, Gemini CLI, Aider, and Generic JSON Hook Protocol (v1 schema).
  • Application & Editor Adapters: Exact window restoration adapters for VS Code, VS Code Insiders, Cursor, Windsurf, VSCodium, Positron, Trae, Apple Terminal, iTerm2, Kitty, Alacritty, Ghostty, Warp, Brave, and Chrome.
  • User Intent Engine: Senses system idle time via CGEventSource. Protects active typing by suppressing focus stealing if keystrokes or mouse clicks occurred within 5 seconds.
  • Attention Arbiter: Priority ordering (permissionRequired > failure > completed > waiting > informational), multi-agent aggregation window (1.5s), and 1000ms focus cooldown.
  • Focus Lock Mode: Temporarily suspend auto-restoration (15m, 30m, 45m, 1h, indefinite) while keeping notification banners active.
  • Local SQLite Storage: Write-Ahead Logging (WAL mode) at ~/.flowback/flowback.sqlite with automated schema migrations and corruption recovery.
  • Menu Bar & Dashboard: Native macOS AppKit status bar item with ⌘1–⌘9 quick restoration and a native SwiftUI Dashboard.
  • Native CLI: flowback command-line executable with doctor, status, refresh, focus-lock, and emit commands.
  • Deterministic Verification Suite: FlowbackTestRunner with 61 unit and integration test assertions.

Changed

  • Streamlined socket IPC handling to stream multi-chunk payloads cleanly across POSIX buffer boundaries.
  • Hardened SQLite parameter binding with SQLITE_TRANSIENT to ensure memory safety under high-concurrency event ingestion.

Fixed

  • Eliminated window thrashing when multiple parallel agents finish within milliseconds of each other.
  • Prevented focus switching into full-screen presentation apps (e.g. Keynote or full-screen video players).

Security

  • Hardened POSIX Unix domain socket permissions to 0600 (accessible exclusively by current user).
  • Zero outbound network requests, zero telemetry, zero prompt or code extraction.

Known Limitations

  • macOS Spaces policy defaults to neverSwitchSpaces to prevent sudden desktop jumping; notification banners are presented on the current Space instead.
