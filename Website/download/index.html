Installation Instructions

  1. Download Flowback-1.0.0-arm64.dmg above and verify the SHA-256 hash.
  2. Double click the .dmg file to mount it, and drag Flowback.app into your Applications folder.
  3. Launch Flowback from Spotlight or Applications. The compass icon will appear in your top menu bar.
  4. Grant Accessibility and Notification permissions when prompted so Flowback can restore windows accurately without stealing focus during typing.

macOS Gatekeeper Verification Notice

Open-source builds produced outside Apple Developer ID programs or self-compiled builds are ad-hoc signed. If macOS displays "Flowback cannot be opened because the developer cannot be verified":

Option 1: Right-click (or Control-click) on /Applications/Flowback.app in Finder, select Open, and confirm in the alert dialog.

Option 2: Remove the quarantine attribute via terminal: 

xattr -cr /Applications/Flowback.app

Upgrading Flowback

Download the latest .dmg, drag Flowback to Applications, and select Replace. Your existing local session database (~/.flowback/flowback.sqlite) and settings are preserved and automatically migrated.

Clean Uninstallation

Flowback removes cleanly without touching your project workspaces:

pkill Flowback
rm -rf /Applications/Flowback.app
# Optional: remove local session history
rm -rf ~/.flowback
