Flowback Privacy Manifesto

“Flowback knows WHERE you were, not WHAT you were doing.”

The Privacy Contract

Flowback was engineered from line 1 for developers working on proprietary, sensitive, and air-gapped codebases. Our architectural posture is strictly local-first, least-privilege, and zero-trust.

What Flowback NEVER Observes, Captures, or Stores:

  • ❌ NO Screenshots or Screen Captures: Flowback never captures video or display buffers.
  • ❌ NO Keystroke or Keylogging: Idle detection queries system elapsed seconds via CGEventSourceSecondsSinceLastEventType; it cannot inspect which keys are pressed.
  • ❌ NO Mouse Coordinates or Cursor Tracking: Flowback does not record pointer trajectories.
  • ❌ NO Source Code or File Contents: Flowback stores folder paths and window IDs, never source code lines or git diffs.
  • ❌ NO Environment Variables, API Keys, or Secrets: Hook dispatchers strip sensitive tokens.
  • ❌ NO Telemetry, Analytics, or Remote Crash Dumps: The binary contains zero networking libraries and makes zero outbound HTTP/TCP calls.
  • ❌ NO Accounts or Cloud Sync: No user registration, no telemetry keys.

What Flowback DOES Observe & Store Locally:

To restore you to the correct working window, Flowback records only minimal structural metadata in local SQLite:

Field Purpose Example
bundleIdentifier Which app was active com.microsoft.VSCode
processIdentifier Target process ID 4821
windowIdentifier Target window ID 42
windowTitle Workspace title match matchday — Visual Studio Code
workspacePath Project directory /Users/name/src/matchday
timestamp Session start / stop time 2026-10-16T09:00:00Z

Local Storage & Data Deletion

All data remains on your physical Mac at:

~/.flowback/flowback.sqlite

Sessions older than 30 days are automatically pruned during database maintenance. You can permanently wipe all Flowback storage, settings, and socket references at any time:

rm -rf ~/.flowback

macOS Permissions Rationale

Accessibility (AXUIElement)

Required to query window IDs and perform kAXRaiseAction. If denied, Flowback falls back to application-level switching without errors.

Notifications (UNUserNotificationCenter)

Required to deliver interactive alert banners when you are actively typing in another application.
