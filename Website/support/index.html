Why Your Support Matters

Flowback is built and maintained by independent developers dedicated to native speed, privacy, and calm developer experiences. Here is where contributions go:

🚀

Build Useful Features & Integrations

Expand agent ecosystem adapters (Aider, Claude Code, Codex, Antigravity, Gemini CLI) and editor window controllers (VS Code, Cursor, Xcode, Ghostty, iTerm2).

🎯

Fix Bugs & Improve Reliability

Strengthen focus arbitration, eliminate edge-case window thrashing, optimize Accessibility (AXUIElement) query speeds, and benchmark race conditions.

🍏

Maintain Flowback as macOS & AI Tools Evolve

Maintain compatibility with current and upcoming macOS versions (Sonoma, Sequoia, and beyond), Swift 6 compiler updates, and Apple Silicon hardware.

🛡️

Keep Building an Independent Developer Tool

Support sustainable development with zero tracking, zero telemetry, and zero artificial paywalls. Flowback remains an honest, offline-first tool for developers.
