## 2. Screenshot Provenance & Surface Inventory

All 15 image artifacts reside in [`Docs/audits/screenshots/`](file:///Users/abin/workspace/projects/flowback/Docs/audits/screenshots/) and were generated by [`VisualParitySuites.swift`](file:///Users/abin/workspace/projects/flowback/Sources/FlowbackTestRunner/VisualParitySuites.swift).

### Generation Methodology
1. **Host Environment:** An offscreen AppKit `NSWindow` is instantiated with explicit dimensions (`880 × 620 pt`), backing store, and target appearance (`.darkAqua`, `.aqua`, or `.accessibilityHighContrastDarkAqua`).
2. **View Embedding:** The target SwiftUI view hierarchy (`DashboardView`) is hosted within an `NSHostingView` attached to the window's `contentView`.
3. **Background Compositing:** The graphics context (`NSBitmapImageRep` at 2x Retina: `1760 × 1240 px`) is pre-filled with the active appearance's `NSColor.windowBackgroundColor` before executing `hostingView.cacheDisplay(in:to:)`.
4. **Distinction:** These images represent pixel-accurate offscreen vector-rasterizations of Flowback's view tree. They are **not** captured from an actively running user session via ScreenCaptureKit.

## 5. Accessibility Audit: Substantiated vs. Unsubstantiated Claims

### Substantiated Claims
- **Dark Mode Card Text:** Primary white text (`#FFFFFF`) on dark card (`#282828`) achieves **14.74:1** (exceeds WCAG AA 4.5:1 requirement). Secondary text (`#A0A0A0`) achieves **5.63:1**.
- **Light Mode Card Text:** Primary dark text (`#1A1A1A`) on light card (`#FFFFFF`) achieves **17.40:1**. Secondary text (`#5E5E5E`) achieves **6.47:1**.
- **Light Mode Status Indicators:** Custom luminance-tuned status colors in `ThemeTokens` all exceed 4.5:1 on white card surfaces:
  - Running (`#0D61C7`): **5.92:1**
  - Completed (`#147A38`): **5.40:1**
  - Permission Required (`#B85205`): **4.97:1**
  - Failed (`#BF1F24`): **6.11:1**
- **Non-Color State Perception (WCAG 1.4.1):** Every status badge incorporates an SF Symbol glyph (`arrow.triangle.2.circlepath`, `checkmark.circle.fill`, `hand.raised.fill`, `clock.arrow.circlepath`), ensuring state is recognizable without color vision.
- **macOS Increase Contrast Adaptation:** `ThemeTokens.isHighContrastActive` checks `NSAppearance.currentDrawing()` and `NSWorkspace.accessibilityDisplayShouldIncreaseContrast`, increasing card border width to `1.2pt` and border opacity to `35%`.

### Unsubstantiated / Qualified Claims
- **Dark Mode Small Badge Text:** In dark mode, system `Color.blue` (4.04:1), `Color.purple` (4.18:1), and `Color.red` (4.33:1) meet the **3.0:1 requirement for graphical objects and UI components** (WCAG 2.1 Criterion 1.4.11), but do not strictly reach 4.5:1 for normal body text unless Increase Contrast is enabled.
- **Global Compliance Scope:** While measured components pass WCAG AA, full WCAG 2.1 AA certification requires comprehensive auditing across dynamic user-generated content, third-party terminal ANSI outputs, and interactive states.

## 6. Functional & Native macOS Desktop Ergonomics

1. **Native Main Menu (`setupStandardMainMenu`):**
   - Flowback wires native AppKit `NSMenu` items:
     - **App Menu:** About, Hide (`⌘H`), Hide Others (`⌥⌘H`), Quit (`⌘Q`).
     - **Edit Menu:** Undo (`⌘Z`), Redo (`⇧⌘Z`), Cut (`⌘X`), Copy (`⌘C`), Paste (`⌘V`), Select All (`⌘A`).
     - **View Menu:** Overview (`⌘1`), Agent Sessions (`⌘2`), Timeline (`⌘3`), Protected Applications (`⌘4`), Diagnostics (`⌘5`), Settings (`⌘6`), and Refresh Sessions (`⌘R`).
     - **Window Menu:** Close Window (`⌘W`), Minimize (`⌘M`).
2. **Keyboard Focus & Search Clearing:**
   - Search text fields support standard AppKit editing shortcuts (`⌘A`, `⌘C`, `⌘V`) and Escape key clearing.
3. **Preset Safety:**
   - Preset additions in `ApplicationsView` append only to the in-memory/persisted `protectedApplications` string array. They do not alter user focus policies, cooldown timings, or database records.
